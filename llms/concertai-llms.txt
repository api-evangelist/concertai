# ConcertAI

> ConcertAI is a healthcare AI and real-world data company for oncology and other complex
> diseases. It combines curated real-world clinical, genomic and imaging data with applied AI
> for life sciences, biopharma and provider organizations. ConcertAI publishes NO public
> developer portal, API reference, or machine-readable specification. The only anonymously
> readable machine-readable documents it serves are the OpenID Connect discovery documents on
> the identity hosts fronting its authenticated Precision platform.

## Not published

- No OpenAPI, Swagger, GraphQL, AsyncAPI or Protobuf specification on any reachable host.
- No developer portal, API reference, getting-started guide or changelog.
- No MCP server and no A2A agent card. The HTTP 200s returned for `/.well-known/agent-card.json`
  on precision.concertai.com and starbi.concertai.com are single-page-app soft-404s — the same
  HTML shell is returned for a random control path — and are NOT agent cards.
- No SDKs or client libraries on npm, PyPI or any other public registry; the ConcertAI GitHub
  organization exists but has zero public repositories.
- No security.txt, no vulnerability-disclosure page, no trust center, no status page.
